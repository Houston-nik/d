Живая версия: https://houston-nik.github.io/d/land-edu-r6w3/
Репозиторий: Houston-nik/d, папка land-edu-r6w3/. Старая версия: old-backup/index.html.

Размеры webp: hero 20 и 36 КБ, about 16 и 28 КБ (srcset).

## Шрифты (Google Fonts, OFL, локально, cyrillic + latin)
Tenor Sans (заголовки), Onest (текст).

## Форма
Как и на старой странице, обработчика на сервере нет: только проверка в браузере и сообщение об успехе. Данные никуда не отправляются и не сохраняются. Без галочки согласия отправка блокируется (кнопка серая, при клике показывается ошибка). Ссылка на policy.html (шаблон-заглушка).

## Что не перенесено со старой страницы
Блок «SEO-структура сохранена» (пояснение к редизайну для демо, не контент для клиента), модальное окно и макет уведомления в Telegram. Крошки, title и description сохранены.
