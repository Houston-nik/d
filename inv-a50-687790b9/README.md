# Сайт приглашения (v1)

Статика: `index.html`, `style.css`, `app.js`, `config.js`, `guests.json`, `img/`. Ничего не собирать, открыть через любой статический сервер (`python3 -m http.server`), от `file://` не работает загрузка гостей.

- `?g=<id>`: личная ссылка (приветствие на конверте и обложке, подстановка имени). Список гостей `guests.json` содержит ПРИМЕРЫ (`demo-*`).
- `config.js`: `ENDPOINT` (пусто = демо-режим, ответ хранится в localStorage), время события, точка карты.
- Визуальные метки `[уточнить]`: места, где нужны данные от Андрея. Перед публикацией все убрать.
- Шрифты Cormorant Garamond и Golos Text подключены с Google Fonts. Для публикации лучше положить файлы рядом (offline, скорость, Россия).
- `img/hall-*.jpg`: фото с сайта площадки, стоят только для макета, нужно согласие; `img/route-scheme.jpg`: схема Андрея.
- `<meta name="robots" content="noindex">`: страницу не индексировать.
